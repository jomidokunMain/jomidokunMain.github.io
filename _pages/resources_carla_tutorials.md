# CARLA Simulator Tutorials

This page will collect practical tutorial notes for using the **CARLA simulator** in automated driving, scenario design, and human-centered transportation research.

## Planned Tutorial Series

1. **Getting Started with CARLA**  
   Installation, basic setup, and running the simulator.

2. **Python API Basics**  
   Connecting to CARLA, spawning actors, controlling vehicles, and collecting data.

3. **Sensors and Data Collection**  
   Camera, LiDAR, radar, GNSS, IMU, and data logging workflows.

4. **Traffic and Scenario Design**  
   Using traffic managers, pedestrians, maps, weather, and scenario logic.

5. **CARLA with Unreal Engine 4 and Unreal Engine 5**  
   Notes on environment setup, maps, assets, and simulation customization.

6. **Human Factors and Automated Driving Applications**  
   Designing CARLA scenarios that support research on driver behavior, trust, transparency, takeover situations, and human-machine interaction.

## Long-Term Goal

The goal is to build a practical resource for students and researchers who want to use CARLA as a simulation platform for automated driving and human-centered intelligent transportation research.
